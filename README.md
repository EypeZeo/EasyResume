# EasyResume

本地求职工作台：核对简历、整理岗位、解释筛选结果，生成有事实依据的沟通草稿。自有代码 MIT，无工具账号、无云端数据库。设计依据为 [设计基线 v1.0](docs/PLAN.md)，实际进度见 [验证状态](docs/STATUS.md)。

## 当前版本

- DOCX、文本 PDF、TXT 本地预填；学历、在读、技能与相关年限由用户确认；扫描件提示改用文本版或手填。
- 粘贴职位原文 → 规则预填 → 修正保存，保留字段证据；支持多简历和策略版本。
- 排除 / 待核实 / 冲刺 / 候选，区间评分、解释、放宽预览、核实问题、收藏、黑名单与撤销。
- 基于已确认事实的模板招呼、草稿自动保存、人工维护进度及首次联系策略归因统计。
- CSV 与脱敏备份、校验后合并恢复；恢复不覆盖当前执行账本，不恢复授权。
- BOSS **实验性只读扩展**，支持显式读取当前页面和保存；页面变化先核对。真实平台兼容性尚未通过60职位观察和21天复测。

**所有平台发送能力关闭**。立即沟通、预设招呼、附件发送和成功反馈尚待真实验证；不能把点击、HTTP 200 或人工进度当作自动发送成功。AI/Ollama、OCR、企业核验、地图、前程无忧和智联适配尚未实现。

## Windows 测试启动包

本机构建后运行 `artifacts/windows/EasyResume/EasyResume.exe`，必须保留整个同名目录。无需安装 Python / Node。数据保存在 `%LOCALAPPDATA%\EasyResume`；浏览器打开本机地址，关网页不会停止服务，关闭终端或 Ctrl+C 停止。重复启动同一数据目录会打开已有服务；端口被其他程序占用时自动选用相邻端口。

当前为**未签名测试构建**，尚未经独立干净 Windows / Defender 环境验收。遇到系统警告可停止运行并核对来源、签名及散列；不要关闭系统防护。仓库不包含生成的 EXE 或真实个人数据。

## 从源码启动

开发依赖 Python 3.12+（推荐3.12）、uv、Node 22+ 和 pnpm 11.7。安装依赖需要网络；安装完成后的本地规则流程无需外部服务。

```powershell
uv sync --frozen
pnpm install --frozen-lockfile
pnpm build
uv run easyresume
```

也可双击 `启动 EasyResume.cmd`。仅做前端开发时，先用 `uv run easyresume --dev --no-browser` 启动后端，再执行 `pnpm --filter @easyresume/workbench dev`。

首次使用建议：填写或导入简历并确认 → 保存策略 → 粘贴职位并检查预填 → 查看待核实原因和下一步 → 收藏。页面上的“合成示例”仅在主动点击后写入，所有示例有明确标记。

### 只读扩展

1. Chrome/Edge 扩展管理页打开开发者模式，加载 `apps/extension/.output/chrome-mv3`（构建包中为 `extension`）。
2. 在本地工作台“设置”生成5分钟内有效的一次性配对码；在扩展中输入工作台实际地址与配对码。
3. 用户自行登录 BOSS、打开职位页面，点击扩展“读取当前页面”，核对后保存。默认不自动翻页或点击平台按钮。
4. 窄侧栏只用于当前页面；完整简历和策略编辑在工作台完成。读取失败或出现验证码时停止操作并回到平台人工处理。

扩展凭据仅有只读采集权限，不可读取简历、创建授权或发送。更换后端端口请重新连接；恢复备份会撤销旧连接。不能用昵称证明账号身份。

平台协议、权限和风控可能限制第三方工具；存在触发验证或账号限制的风险，本项目不宣称取得平台授权。仅在允许范围内使用；不绕过验证码。只读也不等于平台授权。验证记录与未通过项见 [平台验证方法](docs/PLATFORM_VALIDATION.md)。

## 隐私与恢复

| 功能 | 数据去向 | 默认 |
|---|---|---|
| 简历/职位预填、匹配、模板 | 本机服务和SQLite | 开；不上传云端 |
| 扩展采集 | 用户打开页面的职位片段 → 已配对本机服务 | 需主动读取保存 |
| 平台登录 | 用户自己的浏览器 | 服务不取得Cookie/Token |
| 云端AI/Ollama/工商/地图 | 尚未接入 | 关 |
| CSV/备份 | 用户选择的本地文件 | 不含聊天、HR信息、密钥、简历原件与证据原文 |

上传文件的二进制不持久保存，提取文本与画像保存在本机。删除画像会删除其版本分支及关联草稿/评估，并解绑策略，保留其他画像数据；未绑定的输入草稿应自行清空。必要执行账本不随备份恢复回滚。默认备份是有意删减的历史，恢复后证据和原文缺失并非数据损坏，画像需要重新确认。外部备份不会随删除自动清除。本机数据目录应按个人隐私文件保护。

## 验证与构建

```powershell
uv run pytest -q
uv run ruff check backend tests scripts
uv run python scripts/check_fixtures.py
pnpm typecheck
pnpm test
pnpm build
pnpm generate:api
powershell -NoProfile -File scripts/build.ps1
```

`tests/e2e/smoke.py` 使用隔离 Chrome 会话测试本地合成数据；`extension_smoke.py` 加载真实MV3构建，但BOSS响应全部由合成夹具拦截。请使用独立测试数据目录，不能据此声称真实BOSS已兼容。CI测试不接触真实招聘账号。

解析按内容识别并在可终止子进程运行，限制20MB / 50页 / DOCX展开100MB / 30秒 / 512MB；规则预填并不保证准确。未知信息不伪造，复杂要求保留待确认。历史评估保留职位、策略及算法快照；删除对应画像后不能继续完整复算该画像相关结果。
