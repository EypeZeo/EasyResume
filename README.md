# EasyResume 使用手册

**简体中文** · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

EasyResume 帮你整理简历、筛选岗位，并准备沟通草稿。先检查简历中的教育和工作经历，再粘贴岗位描述，就能看到匹配理由、待确认条件和下一步。

**本地验证版 v0.2.0-beta.2**：如果已收到本地测试目录，直接打开 `本地验证/启动 EasyResume.cmd`，不用再次从 GitHub 下载。先关闭旧版的运行窗口。扩展固定从 `本地验证/extension` 加载；以后更新后在扩展管理页点“重新加载”，再刷新 BOSS 页面。下面的下载链接仍指向已公开的 beta.1，不代表 beta.2 已发布。

## 1. 下载并打开

1. 打开 [Windows 测试版下载页](https://github.com/EypeZeo/EasyResume/releases/tag/v0.2.0-beta.1)。页面下方 **Assets** 是附件列表；GitHub 的 **Source code** 是源码，不是安装包。
2. 下载 `EasyResume-v0.2.0-beta.1-windows-x64.zip`。适用于 Windows x64，无需安装 Python 或 Node。
3. 右键 ZIP → **全部解压缩**，选择一个容易找到的文件夹。不要直接在压缩包内运行，也不要单独移动 EXE。
4. 打开解压后的 `EasyResume` 文件夹，双击 `EasyResume.exe`。浏览器会自动打开工作台，另有一个运行窗口，请保持它开启。

如果浏览器没有自动打开，复制运行窗口中显示的 `http://127.0.0.1:…` 地址到浏览器。它指向你自己电脑上的工作台。关掉网页不会退出程序；关闭运行窗口即可退出。再次使用时重新双击 EXE。

这是**未签名测试版**。如 Windows 或安全软件阻止启动，请停止并核对下载来源和发布页的 SHA-256 校验值，或等待已签名版本；不要关闭防护软件。独立干净 Windows 环境验收进度见 [验证状态](docs/STATUS.md)。

## 2. 导入并检查简历

1. 点击左侧 **我的简历 → 选择简历文件**，上传 DOCX、文本 PDF 或 TXT，也可以使用 **粘贴简历原文**。在 **检查识别建议** 中检查，再点击 **采用所选建议**。
2. 检查 **教育经历**：学校、学历、入学时间、结束时间，以及是否在读。只有年份时可以保留年份；不要为凑完整而猜月份。
3. 检查 **工作经历**：公司、岗位、工作类型、起止时间和是否在职。实习与兼职单独显示，重叠工作不会重复计算年限。
4. 检查 **技能**，补充漏掉的内容，移除不属于自己的技能。点击原文入口可以对照依据。
5. 对检查过的记录勾选 **已核对**，点击 **保存简历版本**。若已有筛选策略，按页面提示选择是否让当前策略使用这个版本。

工作年限无法计算时，先补全对应经历的月份及类型。**重新识别**会展示建议；检查后再应用，不会替你确认事实。修改暂存为草稿，正式保存后才用于筛选。旧 DOC 请先用 Word/WPS 另存为 DOCX；扫描 PDF 请换文本版或手动填写。

### 可选：让 AI 辅助整理

本地解析不需要 AI。需要时在 **设置与连接 → 关于与帮助** 配置 AI 服务地址、模型和 API 凭据（例如 DeepSeek 提供的配置）。密钥仅保存在本次运行的内存中，重启后需要重新填写。回到简历页点击 **AI 辅助识别**，检查目标服务和脱敏预览，删除仍包含个人信息的内容，再点击 **确认发送脱敏文本**。只发送预览中的文本，不发送原文件；自动脱敏可能遗漏，请检查后再确认。

等待期间可取消；失败或超时不会清空本地结果。AI 返回的是待检查建议，接受并保存后才用于筛选。服务可能收费，凭据不包含在日志或备份中。

## 3. 导入职位并筛选

1. 在 **筛选策略** 选择已保存的简历，设置岗位方向、城市、薪资和不可接受条件，保存策略。
2. 在 **岗位工作台** 点击 **导入职位**，粘贴招聘网站上的职位描述，补充职位名、公司名和链接。
3. 检查预填内容并保存岗位。未写明的福利保持未知，不要当作没有。
4. 查看结果，收藏值得进一步了解的岗位。

| 结果 | 可以做什么 |
|---|---|
| 候选 | 查看匹配理由，准备沟通 |
| 待核实 | 查看阻塞条件，补充资料或生成核实问题 |
| 冲刺 | 资格存在差距，单独决定是否尝试 |
| 排除 | 查看排除理由；发现误判时修正资料或策略 |

评分表示当前规则下的匹配范围，不是录用概率。候选为零时先看主要原因，可预览放宽条件的效果，再决定是否修改策略。

在岗位详情可生成招呼或核实草稿，到 **沟通与记录** 检查、修改和复制。**复制不等于发送**：目前需要你自己到招聘平台粘贴发送，并在工作台记录结果。

## 4. 可选安装浏览器扩展

不装扩展也可以使用前面的全部手动流程。扩展目前为 BOSS 读取测试功能，真实页面可能变化，不支持自动发送。

1. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
2. 打开 **开发者模式** → **加载已解压的扩展程序**，选择测试包中的 `extension` 文件夹。也可下载单独的扩展 ZIP，先解压再选中含 `manifest.json` 的文件夹。
3. 工作台打开 **设置与连接 → 浏览器扩展**，点击 **生成连接码 → 复制连接码**。
4. 点击浏览器中的 EasyResume 扩展图标，将完整的五组数字粘贴到 **工作台连接码**，点击 **连接工作台**。连接码五分钟内有效，只能使用一次。beta.1 的旧界面将其称为“连接信息”。
5. 自行登录 BOSS 并打开职位列表或详情，点击 **读取当前职位页**，检查结果后点击 **保存到工作台**。新安装后可能需要刷新职位页。

扩展打开时每五秒自动检查连接，状态变化会有简短提示。“工作台离线”时先启动 EXE；“连接已失效”时重新生成连接码。“未检测到扩展活动”可能只是弹窗已关闭，不等于授权失效。不要把连接码发给别人。

推荐页没有读到岗位时，先点击一个岗位展开右侧详情；仍失败可以在招聘页选中单个岗位的标题和正文，再点 **读取选中的职位文字**。选区首行会作为标题，公司等信息需要在工作台核对。这个备用入口不等于登录推荐页已完成实测。

扩展只按你的操作读取当前页面。平台规则可能限制第三方工具；出现验证码、账号异常或读取失败时，停止扩展操作并在平台处理。支持范围和实测证据见 [平台验证说明](docs/PLATFORM_VALIDATION.md)。

## 5. 备份、恢复和升级

- **备份**：打开 **设置与连接 → 数据管理 → 导出备份**，保存下载的文件。
- **恢复**：点击 **从备份恢复**，选中备份，检查新增和跳过数量，再确认。已有记录不会被同 ID 的备份记录覆盖。
- **备份省略内容**：简历原件、姓名、原文及证据片段、HR 个人信息、聊天、连接凭据和 AI 密钥。恢复后可能需要重新检查简历及补充证据，这是备份的取舍，不是文件损坏。
- **升级**：先导出备份并退出程序，将新版解压到新文件夹，再启动新版 EXE。不要同时运行两份版本，不要删除用户数据目录。

数据默认在 `%LOCALAPPDATA%\EasyResume`，与程序文件夹分开。删除简历不会删除你另行保存的外部备份。完整迁移、测试环境恢复说明见 [开发与维护](docs/DEVELOPMENT.md)。

## 6. 常见问题

| 遇到的问题 | 处理方法 |
|---|---|
| 简历读不准 | 检查经历记录；重新识别的建议需确认，也可直接手动修正 |
| PDF 没有文字 | 可能是扫描件，改用文本 PDF、DOCX 或手填 |
| 浏览器页面打不开 | 保持运行窗口开启，使用窗口显示的实际地址；端口被占用时地址可能变化 |
| 扩展已连接但读不到岗位 | 刷新职位页，打开职位详情再试；仍失败可粘贴原文导入 |
| 文件夹里找不到 EXE | 确认下载的是 Windows ZIP，而非 GitHub 的 Source code；检查完整解压和安全软件记录 |
| AI 请求失败 | 检查服务地址、模型、余额及网络；保留本地结果，修正配置后手动重试 |
| 升级后提示数据库错误 | 停止运行，保留原数据和错误提示，不删除数据库尝试重建 |

如需反馈问题，请使用 [GitHub Issues](https://github.com/EypeZeo/EasyResume/issues)，附上版本、操作步骤和已遮盖个人信息的截图。不要上传真实简历、凭据或数据库。

## 7. 当前范围与开发入口

可用：本地简历与岗位整理、规则筛选、可选 AI 识别建议、沟通草稿、备份恢复及 BOSS 只读测试扩展。尚不支持自动发送、OCR、企业自动核验、地图通勤、前程无忧和智联采集。真实平台兼容性及真实简历准确率需要分别验证。
