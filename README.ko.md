# EasyResume 사용 안내서

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

EasyResume는 이력서를 정리하고 채용 공고를 비교하며 연락 초안을 만드는 도구입니다. 앱 화면은 현재 중국어이므로 실제 버튼 이름을 함께 표시했습니다.

**로컬 테스트 버전 v0.2.0-beta.5:** 로컬 테스트 폴더가 있다면 이전 앱 실행 창을 닫고 `本地验证/启动 EasyResume.cmd`를 실행하세요. 확장은 고정된 `本地验证/extension` 폴더에서 로드하고, 업데이트 후 확장 관리 화면에서 새로고침한 다음 작업 화면과 채용 페이지를 새로고침하세요. 아래 다운로드 링크는 공개된 beta.1입니다. 자동 연결, 智联 및 일괄 읽기는 로컬 beta.5 테스트 기능입니다.

## 1. 다운로드 및 실행

1. [Windows 테스트 버전](https://github.com/EypeZeo/EasyResume/releases/tag/v0.2.0-beta.1)의 **Assets**에서 `EasyResume-v0.2.0-beta.1-windows-x64.zip`을 받습니다. “Source code”는 실행 패키지가 아닙니다.
2. ZIP을 오른쪽 클릭하고 **모두 압축 풀기**를 선택합니다. ZIP 안에서 실행하거나 EXE만 옮기지 마세요.
3. `EasyResume` 폴더의 `EasyResume.exe`를 두 번 클릭합니다. Windows x64용이며 Python이나 Node는 필요 없습니다.
4. 브라우저에 작업 화면이 열립니다. 함께 열리는 실행 창을 유지하세요.

브라우저가 안 열리면 실행 창의 `http://127.0.0.1:…` 주소를 복사해 입력합니다. 같은 컴퓨터의 앱 주소입니다. 브라우저만 닫으면 종료되지 않습니다. 실행 창을 닫아 종료하고 다음에 EXE를 다시 실행하세요.

**서명되지 않은 테스트 버전**입니다. Windows나 보안 프로그램이 차단하면 중단하고 출처와 SHA-256을 확인하거나 서명된 버전을 기다리세요. 보안을 끄지 마세요. 독립된 깨끗한 Windows 테스트 여부는 [검증 상태](docs/STATUS.md)에 있습니다.

## 2. 이력서 가져오기 및 확인

1. **我的简历**(내 이력서) → **选择简历文件**(파일 선택)에서 DOCX, 텍스트 PDF, TXT를 선택합니다. **粘贴简历原文**에 글을 붙여 넣어도 됩니다.
2. **检查识别建议**(제안 확인)를 검토하고 **采用所选建议**(선택한 제안 적용)를 누릅니다.
3. **教育经历**(학력)에서 학교, 학위, 입학·종료 시점, 재학 여부를 확인합니다. 월을 모르면 연도만 남기세요.
4. **工作经历**(경력)에서 회사, 직무, 형태, 기간, 재직 여부를 확인합니다. 인턴과 시간제는 따로 표시하며 겹친 기간은 중복 계산하지 않습니다.
5. **技能**(기술)의 누락·오류를 고치고 원문을 확인합니다. 검토한 항목에 **已核对**를 표시합니다.
6. **保存简历版本**(이력서 버전 저장)을 누릅니다. 현재 전략에 새 버전을 쓸지는 직접 선택합니다.

기간을 계산할 수 없으면 해당 경력의 연월과 형태를 보완합니다. 불명확한 값을 경력 0으로 간주하지 않습니다. **重新识别**(다시 인식)의 제안도 확인 후 적용합니다. 편집 초안과 평가에 쓰는 저장 버전은 별개입니다. 구형 DOC는 Word/WPS에서 DOCX로 바꾸고, 스캔 PDF는 텍스트 버전이나 직접 입력을 사용하세요.

### 선택 기능: AI 도움

AI 없이도 로컬 분석이 가능합니다. **设置与连接 → 关于与帮助**(설정 및 연결 → 도움말)에서 DeepSeek 등 제공 업체의 서비스 주소, 모델, API 키를 입력합니다. 키는 실행 중 메모리에만 보관되며 재시작하면 다시 입력해야 합니다.

이력서 화면의 **AI 辅助识别**에서 전송 대상과 개인정보 제거 미리보기를 확인하고 남은 개인정보를 삭제한 뒤 **确认发送脱敏文本**을 누릅니다. 원본 파일이 아닌 미리보기 텍스트만 보냅니다. 자동 제거가 놓치는 내용이 있을 수 있으므로 직접 확인하세요. 서비스 요금이 발생할 수 있습니다.

대기 중 취소할 수 있습니다. 실패나 시간 초과에도 로컬 편집은 유지됩니다. 제안은 확인하고 저장해야 평가에 쓰입니다. 키는 로그나 백업에 포함되지 않습니다.

## 3. 공고 가져오기 및 비교

1. **筛选策略**(선별 전략)에서 이력서, 희망 직무, 도시, 급여, 수용할 수 없는 조건을 정하고 저장합니다.
2. **岗位工作台**(공고 작업 화면) → **导入职位**(공고 가져오기)에 설명을 붙이고 직무명, 회사명, 링크를 추가합니다.
3. 추출 정보를 확인하고 저장합니다. 언급되지 않은 복지는 알 수 없음으로 유지합니다.
4. 이유를 읽고 알아볼 가치가 있는 공고를 저장합니다.

| 결과 | 다음 행동 |
|---|---|
| 候选 — 후보 | 적합 이유를 확인하고 연락 준비 |
| 待核实 — 확인 필요 | 모르는 조건을 보완하거나 질문 작성 |
| 冲刺 — 도전 | 자격 차이를 고려해 개별 결정 |
| 排除 — 제외 | 이유를 보고 오판이면 자료나 전략 수정 |

점수는 규칙에 따른 적합 범위이며 채용 확률이 아닙니다. 후보가 없으면 원인을 보고 조건 완화 결과를 미리 본 뒤 변경하세요.

상세 화면에서 인사말·질문 초안을 만들고 **沟通与记录**(연락 및 기록)에서 편집·복사합니다. **복사는 전송이 아닙니다.** 사이트에서 직접 보내고 실제 결과를 기록하세요.

## 4. 선택 사항: 브라우저 확장

확장 없이도 수동으로 사용할 수 있습니다. 아래는 로컬 **beta.5** 안내입니다. BOSS·智联의 오른쪽 상세 읽기와 사용자가 시작하는 일괄 읽기를 시험 지원합니다. 공개 beta.1은 연결 코드를 사용하는 이전 BOSS 원형입니다. 페이지 변경으로 실패할 수 있으며 자동 전송은 지원하지 않습니다.

1. Chrome에서 `chrome://extensions`, Edge에서 `edge://extensions`를 엽니다.
2. **개발자 모드**를 켜고 압축 해제된 확장 로드로 패키지의 `extension` 폴더를 선택합니다. 별도 확장 ZIP도 먼저 풀고 `manifest.json`이 있는 폴더를 선택합니다.
3. 확장을 설치한 브라우저에서 같은 컴퓨터의 EasyResume 작업 화면을 열면 처음 연결이 자동으로 이루어집니다. 이미 열려 있었다면 한 번 새로고침하세요. 확장에서 **已连接**(연결됨)을 확인합니다.
4. BOSS 또는 智联에 직접 로그인합니다. 왼쪽 목록에서 공고를 고르고 오른쪽 상세가 나타나면 **读取当前职位**(현재 공고 읽기)를 누릅니다. 제목과 회사를 확인한 뒤 **保存到工作台**(저장)를 선택합니다. 설치 직후에는 채용 페이지 새로고침이 필요할 수 있습니다.
5. 여러 공고는 **批量读取**(일괄 읽기)에서 상한을 정한 뒤 **开始批量读取**(시작)를 누릅니다. 기본값은 현재 페이지만 최대 20건입니다. 페이지 이동은 **自动翻页**를 직접 선택해야 하며 기본 2페이지, 최대 100건·5페이지입니다. **暂停 / 继续读取 / 停止任务**(일시 중지·재개·중지)를 사용할 수 있습니다.

확장이 열려 있는 동안 5초마다 연결을 확인하고 변경 사항을 짧게 알립니다. 기존 연결은 포트가 바뀌어도 같은 작업 화면인지 확인한 뒤 다시 연결합니다. 오프라인이면 앱을 실행하세요. “未检测到扩展活动”는 단순히 팝업이 닫힌 상태일 수 있습니다. **断开连接**(연결 끊기)을 선택한 뒤에는 자동으로 다시 페어링하지 않습니다. 다시 연결하려면 **查找并连接工作台**(찾아서 연결)를 누릅니다.

자동 연결이 안 되면 작업 화면의 **设置与连接 → 浏览器扩展 → 生成连接码 → 复制连接码**를 사용합니다. 확장의 **使用连接码**를 열어 5자리씩 5묶음의 숫자를 붙여 넣고 **使用连接码连接**을 누릅니다. 5분 동안 한 번만 유효하며 공유하면 안 됩니다. beta.1에서는 “连接信息”로 표시됩니다.

페이지 이동은 지원되고 식별 가능한 다음 페이지 컨트롤 또는 지원되는 목록 끝 추가 로딩만 사용합니다. 새로 로딩된 한 묶음을 한 페이지로 세며, 지원되는 방법이 없으면 멈춥니다. 무한 스크롤이나 무작정 스크롤하지 않습니다. 일괄 읽기는 대상 탭의 선택된 공고를 바꾸므로 채용 탭을 앞에 유지하고, 중지·오류 안내를 확인한 뒤 재개하세요.

읽기가 실패하면 한 공고의 제목과 설명을 선택하고 **读取选中的职位文字**를 사용하세요. 첫 줄을 제목으로 사용하므로 회사 정보와 함께 확인해야 합니다. **薪资采用特殊字体，待核对**는 특수 글꼴의 급여를 확실히 읽지 못했다는 뜻입니다. 급여가 없다고 판단하지 말고 원래 페이지를 확인하세요.

정식 Chrome에서 智联 읽기·저장·추천 20건을 확인했습니다. 검색 목록도 20건에서 40건으로 자동 추가되어 두 묶음 21건을 처리했고, 17건 추가·중복 4건 건너뛰기로 완료했습니다. BOSS 본문은 실제 페이지 구조로 수정했으며 다시 로드한 뒤 검증합니다.

사이트 약관은 제삼자 도구를 제한할 수 있습니다. 인증·계정 경고가 나오면 확장 작업을 멈추고 사이트에서 처리하세요. [플랫폼 검증](docs/PLATFORM_VALIDATION.md)을 참고하세요.

작업 화면의 **设置与连接 → 浏览器扩展 → 从浏览器整理岗位**에서도 사용할 수 있습니다. 사이트를 선택하고 **定位招聘页面**, **读取浏览器当前职位**를 누르세요. 채용 탭이 여러 개면 하나를 선택합니다. 홈에서는 실제 채용 링크로 한 번만 이동하며, 실패할 때 반복 새로고침하지 않습니다. 일괄 읽기 일시정지·재개·중지도 여기에서 가능합니다.

업데이트 후 사이트 접근 확인이 나오면 채용 사이트 범위가 BOSS와 智联뿐인지 확인하세요. 열려 있는 채용 탭을 찾기 위한 권한이며 Cookie 접근이나 자동 지원은 추가하지 않습니다.

## 5. 백업, 복원 및 업데이트

- **设置与连接 → 数据管理 → 导出备份**(설정 → 데이터 관리 → 백업 내보내기)에서 파일을 저장합니다.
- **从备份恢复**(복원)에서 파일을 고르고 추가·건너뛰기 수를 확인합니다. 같은 ID의 기존 기록은 덮어쓰지 않습니다.
- 원본, 이름, 원문·근거, 담당자 개인정보, 대화, 연결 자격 증명, AI 키는 생략합니다. 복원 후 재확인이나 근거 보완이 필요하며 생략 자료가 없는 것은 손상이 아닙니다.
- 업데이트 전 백업하고 종료한 뒤 새 버전을 새 폴더에 풀어 실행합니다. 두 버전을 동시에 실행하거나 사용자 데이터를 지우지 마세요.

데이터는 프로그램과 별도로 `%LOCALAPPDATA%\EasyResume`에 있습니다. 이력서 삭제로 외부 백업은 삭제되지 않습니다. [개발 및 유지보수](docs/DEVELOPMENT.md)를 참고하세요.

## 6. 문제 해결

| 문제 | 해결 방법 |
|---|---|
| 인식 오류 | 해당 기록 수정 및 재인식 제안 확인 |
| PDF에 텍스트가 없음 | 텍스트 PDF, DOCX, 직접 입력 사용 |
| 화면이 안 열림 | 실행 창을 열고 표시된 실제 주소 사용 |
| 공고 읽기 실패 | 새로고침, 상세 페이지 또는 직접 붙여 넣기 |
| EXE가 없음 | Windows ZIP인지, 압축 해제·보안 기록 확인 |
| AI 실패 | 주소·모델·잔액·네트워크 확인 후 재시도 |
| 업데이트 후 DB 오류 | 중단 후 데이터와 오류 보관, DB 삭제 금지 |

[GitHub Issues](https://github.com/EypeZeo/EasyResume/issues)에 버전, 단계, 개인정보를 가린 화면을 올릴 수 있습니다. 실제 이력서, 키, DB는 첨부하지 마세요.

## 7. 지원 범위 및 개발 자료

이력서·공고 정리, 규칙 선별, 선택적 AI 제안, 초안, 백업을 제공합니다. 로컬 beta.5에는 BOSS·智联 읽기 및 상한이 있는 일괄 처리 테스트 기능이 있으며 공개 beta.1의 범위와 다릅니다. 자동 전송, OCR, 기업 자동 확인, 통근 지도, 前程无忧 수집은 지원하지 않습니다. 실제 사이트 전체 절차와 이력서 정확도는 별도 검증이 필요합니다.
