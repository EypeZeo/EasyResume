# 解析与人工验收标注规范 v1

自动化测试中的简历和职位均为合成内容。尚无真实授权冻结验收集，不能据测试通过宣称95%/80%的真实解析指标。

标注单位为来源文档内的一条教育/工作记录，先人工配对记录，再比较字段。字段分开统计：已完成最高学历、在读学历、毕业年份、教育形式、相关工作年限、技能；职位统计学历值及要求类型、经验下限、固定薪资上下限/周期/口径、薪资月数、休息制度、五险、公积金及派遣。不能将“学历”和“教育”重复记成两项成绩。

- 日期按年月归一化，例如2019.09与2019年9月相同；本版本画像只持有毕业年份，不能据此声明已经抽取完整教育/工作时间线。
- 学历使用固定枚举，研究生需有证据区分硕士/博士；未知不能当正确否定。
- 薪资统一元，范围端点和口径分别比较；综合收入和固定底薪不可互换。
- 每项报告 TP/FP/FN；精确率为TP/(TP+FP)，召回率为TP/(TP+FN)。人工可读但未提取计FN，误提或提错计FP；无正样本的分母标N/A。
- 按来源和模板分离开发集与冻结集。同一模板的改名副本不能横跨两组，合成样例不计入真实来源比例。
- 用户修正结果不计入自动预填准确率。当前规则不支持的复杂表述仍计漏检并回退人工确认。

真实来源的许可、原件与标注保留在Git外，由用户决定存储和删除。仓库只能加入明确合成或已授权脱敏的样本。至少1份样本只能验证入口，无法估计稳定质量；真实使用、平台观察和省时试验另行记录。
