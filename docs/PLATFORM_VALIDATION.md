# 第0批观察协议

仅在用户自己打开且获准访问的页面点击“读取当前页”。不自动滚动、翻页、点击沟通或导出原始HTML，不读Cookie和聊天。

记录至少60个不同职位、2城市。记录用工类型（全职/实习/兼职）与招聘对象（校招/社招），不强制它们互斥。按字段登记可见、提取、人工修正及缺失；导出脱敏JSON计数报告。失败、验证码和登录提示暂停读取，用户处理后手动恢复。

动作观察只能由用户先主动执行有意愿的真实动作，再填写前后基线和稳定结果；禁止发送无意义测试消息。记录对象是否一致、是否预设招呼、正文是否一致、附件请求/平台显示已发送/已读各自证据。HTTP200、旧气泡、乐观气泡、按钮消失不能独立确认。

目前动作均未真实验证，发行扩展没有发送处理器。创建开发测试记录不能解锁生产能力。约21天后复测DOM和字段，不以等待时间代替验证。

整页测试夹具只能提交合成内容；真实夹具在明确授权、脱敏、人工检查后才能提交。真实账号标识、头像、姓名、联系方式、聊天和凭据不进Git。
