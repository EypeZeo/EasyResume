# EasyResume 设计基线 v1.0

日期：2026-10-15。状态：已授权实施。自有代码 MIT。本文件为唯一设计基线，替代早期“纯扩展 / IndexedDB”方案；实现进度见 STATUS.md。

## 目标、架构与范围

帮助用户根据简历与个人要求更快找到值得联系的岗位，减少重复浏览、误筛与重复沟通。衡量总处理耗时、合适岗位数、误排除及有效沟通。

工作台采用 React、TypeScript、Tailwind；本地后端 FastAPI；SQLAlchemy、SQLite、Alembic 是权威数据存储；WXT Manifest V3 扩展只做当前页面短交互。python-docx 和 pypdf 解析 DOCX / 文本 PDF。pytest、Vitest、Playwright 验证，PyInstaller 分发。第三方许可随发行包保留。

无需工具账号或远程服务器。用户自行在 Chrome / Edge 登录招聘平台；不保存平台 Cookie / Token，不实现独立登录浏览器。先验证 BOSS，再接前程无忧、智联。自动筛选、整理、排名、草稿；所有对外沟通、请求及附件发送需单项确认。手动导入不依赖扩展、AI、企业接口、OCR、地图。明确平台限制及账号风险，不宣称获平台授权或永不触发验证。

## 用户流程与数据

首次使用：上传 / 填写简历 → 核对资格字段 → 设置岗位方向、城市与不可接受条件 → 粘贴职位并确认预填 → 查看理由、阻塞和下一步并收藏。高级权重与实验功能按需展开。

简历支持 DOCX、文本 PDF、TXT、手填；旧 DOC 转换，扫描件提示文本版 / 手填。职位粘贴原文，补来源、URL、名称和公司。两者共用“原文 → 预填 → 修正 → 版本保存”；原文与字段并排；已确认未变内容复用；修改只提示受影响部分。多简历独立画像，每策略绑定具体版本。推荐方向需接受，不推断薪资、派遣、夜班或出差意愿。

解析在可终止子进程，限制文件 20MB、PDF 50 页、DOCX 解压 100MB、30 秒、512MB。按内容识别，不执行宏或活动内容，超限可手填。

重要字段保存值 / 范围、片段、来源、观察时间、提取检查、依据类型（页面 / HR / 外部 / 自行核实）、冲突及过期。检查提取不升级事实核验。页面明确声明可初筛；策略可要求更高依据。冲突并存不静默覆盖。企业性质、招聘主体、服务企业、合同主体分开；企业自动核验后置。

待核实显示阻塞、证据及一至两个优先问题，支持看原文、生成追问、补证、暂存、归档与明确改策略。补充后重算；无回复不等于不满足。候选为空显示阻塞统计及放宽预览，预览不改策略。单岗位例外单独记，不伪造核实、不影响全局。

侧栏处理当前岗位，工作台处理跨岗位与配置。卡片先显示结论、理由、未知、下一步，评分按需展开。本地编辑可撤销、草稿自动保存、黑名单 / 归档可恢复。已发送不可普通撤销，结果不明打开平台核对。保存、离线、暂停、失败有文字与恢复路径。

## 资格、评分与反馈

固定优先级：**排除 > 待核实 > 冲刺 > 候选**，保留全部命中原因。黑名单 / 不可接受条件排除；必要未知 / 冲突 / 需复核风险待核实；资格不足冲刺（可严格排除）；其余候选。冲刺不混入普通投递队列。

学历区分已完成、在读、预计毕业、形式；要求区分必需 / 优先 / 可替代。本科优先非硬门槛，本科或经验非 AND；应届按毕业时间，未限定不能擅加全日制。复杂未支持条件待确认。AI 风险提示不能直接定性或排除。

区间加权，默认下限降序，同分区间较窄优先，再按观察时间。预设岗位30、薪资25、福利20、企业15、活跃10。关闭维度在策略级归一化，不按单岗位缺失归一化。

| 维度 | 规则 |
|---|---|
| 岗位 | 岗位方向及确认技能分别计分，词表版本化 |
| 薪资 | 固定月薪达理想100，达底线60，低于0；理想=底线则达即100，范围分别计算端点 |
| 制度福利 | 已启用子条件满足比例，未知保留范围 |
| 企业 | 首选100，可接受50，不偏好0；禁止在资格层排除 |
| 活跃 | 今日100、三日75、一周40、其他明确10；缺失 / 过期未知 |

综合收入不当底薪，薪资月数单列。未知软项[0,100]，硬项未知待核实。活跃超过24小时不作当前分数。企业无偏好及不稳定字段默认关闭。全关闭显示未评分。风险不扣分，分数不覆盖硬要求；分数不是录用概率。评估绑定职位快照、画像、策略与算法版本，旧版可复算，跨策略不可直接比较。P10～P90实验默认关闭、后置、冻结参数，不静默重算。

招呼引用确认事实，模板离线可用，不虚构经历或承诺。统计按首次联系策略 / 版本归因，区分积极、拒绝、未观察、无回复；展示窗口和分母、值得继续岗位、合适面试、耗时、找回误排除。小样本不宣告优胜、不自动改权重。

## 平台操作、安全、生命周期

第0批分开验证打开会话、立即沟通、自定义文字、简历请求、附件。沟通、请求发出、平台显示附件发出、已读不可混成投递。预设招呼不可预览则保持人工，不拿草稿A授权发送B。成功关联动作后新增结果，历史同文、乐观气泡、HTTP200、按钮变化不单独证明；无法判断人工核对。

授权绑定平台、身份模式、对象、职位、类型、正文 / 附件摘要、执行器、版本，60秒有效。先持久化“执行可能发生”，同动作最多派发一次，之后只核对。点击前重查页面 / 暂停；重连重启仅核对。未执行可取消，在途不承诺撤回。内容 / 画像 / 身份 / 适配器变化使旧授权失效。

可靠账号标识优先，昵称非唯一。不能识别用安装实例并说明限制；严格绑定动作人工发送。后端SQLite限频：一个在途、至少60秒、上海自然日10次；失败未知也计数；同账号实例合并，未知平台级保守计数，身份变化不增加额度。断连不放行，验证码 / 额度 / 异常全局暂停。工具额度非全平台额度。

回环监听，Host / Origin / 配对校验；长期凭据只在可信扩展上下文，内容脚本不审批、不任意代理。握手协议 / 实例 / 适配 / 动作版本，不兼容拒绝执行。固定数据目录与单实例锁，重复启动打开已有；仅其他程序占端口才换端口；迁移失败不创建空白库绕过。

仅字段片段，整页调试默认关，24小时到期，启动先清理。默认导出备份无HR个人信息、聊天原文、密钥、简历原件；恢复先预览省略及可能重现的数据。校验后导入不恢复授权、不激活队列、不回滚执行账本和额度；未知保持未知。新安装重新配对且暂停，核对或下一限额周期后才能发送。恢复拒绝新授权，使旧连接失效。删除范围包括原件、提取、画像、草稿；外部备份不能保证删除。云端AI / Ollama / 企业 / 地图默认关，启用说明数据、费用，上传先脱敏预览。外部文字不可授权。

## 批次与验收

| 批次 | 交付与门槛 |
|---|---|
| 0 | 只读扩展、能力表、身份及动作观察、三核心流程原型；真实证据才能声明验证 |
| 1 | 本地启动、解析确认、单策略、分组评分、黑名单CSV；无AI扩展可用 |
| 2 | BOSS读取、侧栏、去重、证据、模板、多画像策略；权限和版本通过 |
| 3 | 确认操作、核对、限频、看板、备份反馈；逐动作真实与故障验收后开放 |
| 4 | AI / 企业 / OCR / 通勤与Windows普通用户包；失败不破坏基础功能 |
| 5 | 51job、智联分别预检与适配，不能用预留接口冒充支持 |

第0批至少60岗位、2城市；全职 / 实习 / 兼职与校招 / 社招分别记录。记录字段来源覆盖、错误与页面形态。用户有意愿的手动操作被动观察，不发测试骚扰。未观察标未验证，网络诊断不默认发行权限。约21天复测是稳定版证据，不阻塞开发；验证码异常立即停，不压力测试。

本次用户授权的最低解析语料为至少1份DOCX / 文本PDF、真实授权不少于一半；单样本只说明入口验证，不能声称泛化准确率。按来源 / 模板隔离开发与冻结验收；教育工作先关联再算精确率95%、召回80%，未达标手填。人工可读失败计漏检。

规则覆盖学历优先、替代、在读、否定、薪资、多冲突。故障覆盖授权 / 派发 / 点击 / 回报中断、历史同文、乐观气泡、身份迁移、旧备份、旧版本，不重复派发不误记成功。真实夹具先脱敏，CI检查，删除恢复一致。

最低可用性：至少1名目标用户安装后10分钟保存值得了解的岗位；候选零时30秒找到原因和下一步。20岗位包括复制导入确认修正的总耗时对照，目标节省30%，同时报误排除。键盘、焦点、文字状态、播报、窄侧栏缩放可用。杀毒开启的干净Windows测安装冲突重复启动升级，未签名如实说明不关闭防护。

每批报告支持矩阵、证据、失败及门槛。字段准确率95%按字段分母报告，不抵消身份或发送误判。首要验证简历确认、岗位解释、待核实是否省时。
