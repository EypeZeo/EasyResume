# 自动打开与无人值守：设计及当前范围

## 现在可以使用

本地验证目录的“启动 EasyResume.cmd”明确使用已安装的正式 Chrome 打开工作台，不修改 Windows 默认浏览器、不创建另一套浏览器资料，也不读取或导出平台登录凭据。

“启动 Chrome 求职工作区.cmd”同时打开工作台、BOSS 职位入口和智联职位入口。服务已经运行时复用现有服务；每次明确点击都会打开这些页面，可能增加标签页，但不是周期循环任务。网页是否成功加载、是否保持登录、是否返回首页，仍由网站决定；打开入口不等于定位或读取成功。

命令行可用 `--browser chrome --open-jobs`；原有默认浏览器模式保留，`--no-browser` 优先禁止所有浏览器启动。找不到正式 Chrome 或启动失败时，服务继续运行并显示工作台地址，不静默切换浏览器。只查找标准安装目录，不开放任意程序执行接口。

扩展已支持工作台重连、用户启动后的有界批量读取、自动加载、暂停和自然末尾停止。这些能力只读，不发送消息或简历。

当前批量要求招聘标签页保持前台；切换标签或隐藏页面会暂停。不承诺锁屏、休眠或浏览器退出后仍能继续，本版不修改Windows电源设置。

## 网页自动刷新与恢复（beta.25 测试功能）

工作台、扩展弹窗和侧栏的批量读取区提供“加载失败时自动刷新一次并恢复”。它默认关闭，与“自动翻页”独立；仅在启动本次任务时选择。运行、恢复及暂停期间不能修改选项。它只刷新选定的招聘网页，不重新加载扩展程序。

1. 用户先选择平台、具体标签页、搜索范围和本次读取上限，再启动一次任务。
2. 明确的列表网络错误或空详情超时可以触发恢复尝试。原内容脚本必须返回与原任务、原文档对应的 `BATCH_STOP`，并确认 `settled`；没有确认原读取步骤完全结束、文档或连接已变化时，不刷新。不会把等待超时当成停止成功。
3. 刷新后必须取得新的文档标识，重新核对平台、同一标签页、窗口、普通或无痕上下文、原 URL 和搜索范围；旧页面节点与旧任务回报不能继续使用。
4. 原队列中的岗位都有公开、稳定、唯一的职位编号时，按编号和队列顺序完整重建原列表，包括此前自动追加的部分。不能只根据同名职位、公司或当前选中行猜测。列表变更、顺序变化或无法完整重建时暂停。
5. 缺少稳定编号时，从新文档列表的第一条重新核对，不沿用旧文档的行号或节点。每条仍需核对当前左右内容；相同记录去重，已有可靠编号对应的岗位信息变化进入待核对，不直接覆盖。无编号且正文变化时可能保留为独立记录，不仅凭同名公司和职位合并。重复核对也计入本次原定条数上限；累计页数和刷新额度不会清零，因此可能先达到上限，再由用户决定是否另开任务。
6. 每个任务最多自动刷新一次，跨任务的两次自动刷新至少间隔五分钟；这与现有空详情重选的五秒间距分别计数。刷新后最多等待45秒让网站加载，明确的网络错误立即暂停；普通加载与明确报错分开处理。刷新仍返回首页、详情仍为空、标识无法对应、遇到验证、不明确遮罩或被切到后台时暂停，不能不断刷新。恢复状态显示当前步骤和刷新尝试次数，可随时暂停或停止；中断恢复不会自动重新开始。
7. 当前观察到的智联左右分栏列表左卡缺少公开编号，适用“从首条重新核对”，不属于从原中断位置直接续读。本轮真实恢复尚未验收；其他页面也以实际结果为准，不以平台名称保证可以恢复。已保存记录保留，无法核对的条目不能算作成功或自然结束。
8. 工作台存在简历、策略或职位编辑草稿时，不刷新工作台。连接短暂中断只重连，不把刷新当作配对或授权恢复。扩展后台重启后，未完成任务保持暂停，重新核对前不自动执行。

手动刷新后不能直接继续旧文档的队列，需停止旧任务并重新开始；没有文档标识的旧版本任务同样处理。

刷新等待会显示最近检查原因：页面响应超时、页面脚本未响应、仍是刷新前页面、缺少页面标识或新页面暂无职位，并记录各类次数。该提示用于区分故障阶段，不表示已确定网络、网站或浏览器的根因。出现已识别的验证异常会立即暂停。

代码与模拟测试用于验证恢复条件、刷新前后中断、保存回报晚到、队列改变、重复岗位及验证码等边界，不能代替真实网站验收。本说明不表示 BOSS 或智联已经完成真实页面“自动刷新后续读成功”验证；实测结果单独记录。

## 刷新后的新手引导

识别智联已知文案“点击消息，可以直接跟招聘方聊天啦~”及唯一安全的“我知道了”按钮，也支持已观察到的图片式消息引导。图片式引导的文字不是网页文本，须核对精确图片来源、专用容器、遮罩和点击位置，不能把任意“我知道了”图片当作关闭入口。每个网页文档最多尝试关闭一次，等待最多一秒确认引导与遮罩消失后才读取；不删页面节点或隐藏样式。其他遮罩、表单、导航按钮或无法唯一识别的提示会暂停。单条读取、批量启动和后续步骤共用该保护。已在真实页面验证点击该图片能关闭引导且不导航；新版扩展自动关闭仍需独立复测。

## 扩展自身更新

“刷新招聘网页”与“重新加载扩展程序”不同。目前使用开发者模式加载本地扩展，覆盖磁盘文件不会使浏览器已加载的旧代码自动更新。本版没有增加扩展自身重载、浏览器管理自动点击或热更新执行通道；真正改变扩展代码后仍需人工重新加载一次。

因此当前版本还不能承诺完全无人值守。无人值守也不包含处理验证码、重新登录、改变筛选要求、对外沟通或投递。
