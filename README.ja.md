# EasyResume 利用ガイド

[简体中文](README.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

EasyResume は履歴書の整理、求人の比較、連絡文の下書きを支援します。アプリは現在中国語のため、実際のボタン名も記載します。

## 1. ダウンロードと起動

1. [Windows テスト版](https://github.com/EypeZeo/EasyResume/releases/tag/v0.2.0-beta.1)の **Assets** から `EasyResume-v0.2.0-beta.1-windows-x64.zip` をダウンロードします。「Source code」は実行用パッケージではありません。
2. ZIP を右クリックして **すべて展開** を選びます。ZIP 内から直接実行したり、EXE だけを移動したりしないでください。
3. 展開した `EasyResume` 内の `EasyResume.exe` をダブルクリックします。Windows x64 用で、Python や Node は不要です。
4. ブラウザーに作業画面が開きます。別に表示される実行ウィンドウは開いたままにします。

自動で開かない場合は、実行ウィンドウの `http://127.0.0.1:…` をブラウザーに入力します。同じパソコン上のアプリのアドレスです。ブラウザーを閉じてもアプリは終了しません。実行ウィンドウを閉じて終了し、再開時は EXE を起動してください。

**署名なしのテスト版**です。Windows やセキュリティソフトが停止した場合は配布元と SHA-256 を確認するか、署名済み版をお待ちください。保護機能は無効にしないでください。クリーン環境での確認状況は[検証状況](docs/STATUS.md)に記載します。

## 2. 履歴書の取り込みと確認

1. **我的简历**（履歴書）→ **选择简历文件**（ファイル選択）で DOCX、テキスト PDF、TXT を選びます。**粘贴简历原文** に文章を貼り付けることもできます。
2. **检查识别建议**（抽出候補の確認）を見て、**采用所选建议**（選択した候補を適用）を押します。
3. **教育经历**（学歴）で学校、学位、入学・終了時期、在学状態を確認します。月が不明なら年だけを残します。
4. **工作经历**（職歴）で会社、職種、雇用形態、期間、在職状態を確認します。インターンとパートは別扱いで、重複期間は二重計算しません。
5. **技能**（スキル）の不足や誤りを直します。原文を参照し、確認した項目に **已核对** を付けます。
6. **保存简历版本**（履歴書の版を保存）を押します。現在の検索条件で新しい版を使うかは明示的に選びます。

経験期間を計算できない場合は該当職歴の年月と形態を補います。不明を経験ゼロと扱いません。**重新识别**（再抽出）の結果も確認後に適用します。下書きと、求人判定に使う保存済み版は別です。古い DOC は Word/WPS で DOCX に変換し、スキャン PDF はテキスト版か手入力にしてください。

### 任意の AI 支援

AI なしでも利用できます。**设置与连接 → 关于与帮助**（設定・接続 → ヘルプ）で DeepSeek などのサービス URL、モデル、API キーを入力します。キーは起動中のメモリーにのみ保持され、再起動後は再入力が必要です。

履歴書画面の **AI 辅助识别** で送信先と匿名化プレビューを確認し、残った個人情報を削除してから、**确认发送脱敏文本** を押します。原本ファイルではなく表示した文章だけを送ります。匿名化には見落としがあり得るため確認してください。サービス料金が発生する場合があります。

待機中はキャンセルできます。失敗やタイムアウトでもローカル編集は残ります。提案は確認して保存するまで判定に使われません。キーはログやバックアップに含まれません。

## 3. 求人の取り込みと比較

1. **筛选策略**（絞り込み条件）で履歴書、希望職種、都市、給与、受け入れられない条件を設定・保存します。
2. **岗位工作台**（求人一覧）→ **导入职位**（取り込み）で求人説明を貼り付け、職種名、会社名、リンクを補います。
3. 抽出内容を確認して保存します。書かれていない福利厚生は「不明」のままにします。
4. 理由を確認し、詳しく知りたい求人を保存します。

| 判定 | 次の行動 |
|---|---|
| 候选 — 候補 | 適合理由を見て連絡を準備 |
| 待核实 — 要確認 | 不明条件を確認するか質問文を作成 |
| 冲刺 — 挑戦枠 | 資格差を踏まえて個別に検討 |
| 排除 — 除外 | 理由を見て、誤りなら資料や条件を修正 |

点数はルール内の適合範囲で、採用確率ではありません。候補ゼロなら理由を確認し、条件を緩めた結果をプレビューしてから変更できます。

求人詳細で挨拶や質問の下書きを作り、**沟通与记录**（連絡・記録）で編集・コピーします。**コピーは送信ではありません**。求人サイトで手動送信し、結果を記録してください。

## 4. 任意のブラウザー拡張

拡張なしでも手動取り込みができます。BOSS 読み取りはテスト機能で、サイト変更で動かなくなる場合があります。自動送信はできません。

1. Chrome で `chrome://extensions`、Edge で `edge://extensions` を開きます。
2. **デベロッパーモード**を有効にして展開済み拡張機能を読み込み、パッケージの `extension` を選びます。拡張単体 ZIP も先に展開し、`manifest.json` のあるフォルダーを選びます。
3. **设置与连接 → 浏览器扩展** で **生成连接信息 → 复制连接信息**（接続情報を生成・コピー）を押します。
4. 拡張の **粘贴工作台的连接信息** に貼り付け、**连接工作台** を押します。期限切れなら生成し直します。
5. 自分で BOSS にログインして求人を開き、**读取当前职位页**（現在の求人を読む）→ 内容確認 → **保存到工作台**（保存）を選びます。初回はページの再読み込みが必要な場合があります。

応答しない場合は EXE を起動し **重新检查连接**（接続を再確認）を押します。バックアップ復元後などに失効したら再接続してください。接続情報を他人に渡さないでください。

サイト規約で第三者ツールが制限される場合があります。認証やアカウント警告が出たら操作を止め、サイト上で対処します。[検証範囲](docs/PLATFORM_VALIDATION.md)も参照してください。

## 5. バックアップ・復元・更新

- **设置与连接 → 数据管理 → 导出备份**（設定 → データ管理 → バックアップ）で保存します。
- **从备份恢复**（復元）でファイルを選び、追加・スキップ件数を確認します。同じ ID の既存データは上書きしません。
- 原本、氏名、原文・証拠断片、採用担当者の個人情報、チャット、接続情報、AI キーは省略します。復元後は再確認や証拠の補充が必要です。省略された内容がないのは破損ではありません。
- 更新前にバックアップして終了し、新版を別フォルダーに展開して起動します。旧版と同時に起動したり、ユーザーデータを削除したりしないでください。

データはプログラムと別の `%LOCALAPPDATA%\EasyResume` に保存されます。履歴書削除で外部バックアップは消えません。技術情報は[開発・保守](docs/DEVELOPMENT.md)を参照してください。

## 6. 困ったとき

| 問題 | 対処 |
|---|---|
| 認識が不正確 | 該当レコードを修正し、再抽出候補を確認 |
| PDF に文字がない | テキスト PDF、DOCX、手入力を使用 |
| 画面が開かない | 実行ウィンドウを開き、表示中のアドレスを使用 |
| 求人を読めない | 再読み込み、詳細ページ、手動貼り付けを試す |
| EXE がない | Windows ZIP か、展開と保護ソフトの履歴を確認 |
| AI が失敗 | URL、モデル、残高、通信を確認して再試行 |
| 更新後の DB エラー | 停止してデータとエラーを保管し、DB を削除しない |

[GitHub Issues](https://github.com/EypeZeo/EasyResume/issues) に版番号、手順、個人情報を隠した画像を添えて報告できます。実際の履歴書、キー、DB は添付しないでください。

## 7. 対応範囲と開発資料

履歴書・求人整理、ルール判定、任意 AI 提案、下書き、バックアップ、BOSS 読み取りテスト拡張を提供します。自動送信、OCR、企業自動照合、通勤地図、前程無憂・智聯の収集には未対応です。実サイトと実際の履歴書の精度は別途検証が必要です。
