# EasyResume 图标

绿色底与文件勾选图形用于工作台、浏览器扩展和 Windows 启动程序。图形基于已安装的 Lucide 0.468.0 `FileCheck2`，按 ISC 许可可免费用于商业和非商业项目，需保留 [许可与署名](LICENSE-LUCIDE.txt)。绿色背景与组合采用项目 MIT 许可；不主张图形的独占商标权。

- `logo.svg`：可编辑矢量源文件。
- `16/32/48/128/256.png`：透明背景 PNG。
- `easyresume.ico`：Windows 图标。
- `scripts/brand_assets.ps1`：Windows 下重新生成与同步资源；需要先安装项目 Node 依赖以读取许可。
